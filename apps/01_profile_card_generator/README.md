# Profile Card Generator

App que genera una tarjeta visual a partir de un formulario: nombre, rol, avatar y bio. Ideal para entender cómo los inputs modifican el UI en tiempo real.

## Funcionalidades

- Formulario con inputs controlados
- Previsualización en tiempo real
- Estilos dinámicos según datos

## Conceptos React

- useState
- controlled components
- props vs state
- separación componente form / componente display

## Estado y datos

React puro — Todo el estado cabe en useState. Usar librerías aquí oscurecería las bases.
Extra opcional: Añade validación básica (campos vacíos), modo dark/light con un toggle, y exporta la tarjeta como PNG con html2canvas.
