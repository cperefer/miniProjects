Tracker visual donde el usuario añade hábitos y marca cuántas veces los ha hecho hoy. Persiste en localStorage al cerrar.
Funcionalidades
Añadir / eliminar hábitos
Incrementar / decrementar contador
Persistencia con localStorage
Reset diario manual
Conceptos React
useState
useEffect (persistencia)
lifting state up
separación de componentes
Estado y datos
React puro — useEffect + localStorage es suficiente. El patrón de persistencia manual es exactamente lo que se debe aprender aquí antes de delegar a una librería.
Extra opcional: Añade fechas para ver histórico semanal, usando useReducer para manejar el estado complejo.
